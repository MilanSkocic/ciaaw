NAME

ices - get the isotopic compositions

LIBRARY

ciaaw library (libciaaw, -lciaaw)

SYNOPSIS

Fortran

function ice(s)result(res)

character(len=*), intent(in) :: s

real(dp), pointer :: res(:,:)

C

double *ciaaw_ices(char *s,int n);

DESCRIPTION

Get all the isotopic compositions of the element s.

Arguments:

s

Element symbol.

RETURN VALUE

(n,3)array

Fortran order array with the mass number, the composition and the uncertainty for the n isotopes.

NULL

If the provided element is incorrect.
