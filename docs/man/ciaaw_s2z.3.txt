NAME
       s2z - get the atomic number

LIBRARY
       ciaaw library (libciaaw, -lciaaw)

SYNOPSIS
       Fortran   function s2z(s)result(res)

                    character(len=*), intent(in)  :: s

                    integer(int32)  :: res

       C         int ciaaw_s2z(char *s,int n,);

DESCRIPTION
       Get the atomic number Z of the element s.

       Arguments:

       s         Element symbol.

RETURN VALUE
       -1        If the element does not have an ICE.
