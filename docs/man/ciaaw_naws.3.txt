NAME
     ices - get all the nuclides' atomic weights

LIBRARY
     ciaaw library (libciaaw, -lciaaw)

SYNOPSIS
     Fortran   function naws(s)result(res)

                  character(len=*), intent(in)  :: s

                  real(dp), pointer  :: res(:,:)

     C         double *ciaaw_naws(char *s,int n);

     Python    naws(s:str)->np.array:

DESCRIPTION
     Get all nuclides' atomic weights of the element s.

     Arguments:

     s         Element symbol.

RETURN VALUE
     (n,3)arrayFortran  order  array  with  the mass number, the atomic
               weight and the uncertainty for the n nuclides  given  by
               ciaaw_nnaw(3).

     NULL      If the provided element is incorrect.
